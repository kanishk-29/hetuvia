
## Synthetic population (Chunk 3)

Generated by `python -m app.cli seed` (seed 42, 300 people). All records have source_system = "synthetic".
Planted data gaps (the answer key, see `PLANTED_KINDS` in `backend/app/adapters/synthetic_generator.py`):
weight_unknown, height_not_collected, stale_bp, completed_screening_no_date, screening_due_date_unknown,
family_history_unknown, family_history_not_collected, no_encounters, missing_dob, missing_language.
Condition codes starting with DEMO- are placeholders, not real clinical codes.
Stale readings keep their value; staleness is judged from the date, not stored as a state.
